# Rahul E. — portfolio

A hand-made paper desk: torn sheets, a wooden desk, six case files that open into blueprints, evidence, field notes and specs, and seven secrets hidden on the desk.

**Live:** https://eduvanthrahul-afk.github.io

Plain HTML, CSS and JavaScript with no build step and no frameworks. Every texture (crumpled paper, torn edges, wood grain, ink stamps) and every sound is generated in code.

| File | What it does |
|---|---|
| `index.html` | the page |
| `styles.css`, `script.js` | papers, torn edges, crumple texture, intro tear |
| `desk.css`, `desk.js` | wooden desk, lamp and UV torch, sounds, the seven secrets |
| `dossier.css`, `dossier.js` | the case-file folders |
| `cases.js` | folder contents: blueprints, notes, specs |
| `cases-code.js` | real code excerpts copied from the project repos |

Run it locally with any static server, e.g. `python -m http.server`.
